Build a tray tracking app for Eman Bakery with 3 branches: Hera, Rahmaniyyah, and Bawadi. The app is for internal users only: admin and branch staff. Salesmen are external records, not app users. Admin creates users and assigns each user to one branch. The app must start with one-time opening stock setup for each branch, then track all tray movements after that. Each salesman must have a profile page showing full transaction history and statement details. Each transaction must record branch, salesman, quantity, date, time, and recorded-by user. The app must block issue if branch stock is insufficient and block return if it exceeds outstanding trays. No transaction history may be overwritten. All changes must remain fully auditable. Build clean dashboards, reports, and strict stock validation.
